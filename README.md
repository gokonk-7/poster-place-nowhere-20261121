A program that draws a vintage travel poster for **Velmora**, a place that isn't there: one crescent islet in a teal sea, one coral lighthouse with its lamp lit, a low golden sun on the horizon, and a ringed planet hanging in the dusk sky above it all. The invented name is set large in the lower band, in a Didone-style serif, so the poster reads at a glance as an invitation to a world that does not exist.

## Run it

```sh
python3 main.py
```

The program copies the poster rendered by `generate.py` to `/output/entry.png`. To re-render the poster from scratch (Pillow, deterministic):

```sh
python3 generate.py
```
